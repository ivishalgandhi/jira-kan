# All epics is a later Board, not a Scope

ADR-0004 deferred a Kanban whose Cards are Epics to a later Board with its own opener, not a select toggle. That opener is All epics, a sibling of All stories. It is not typing `-tEpic` into Scope, not a Preset, not a Pipe, and not a second process. List is already `jira issue list -tEpic --raw`; Move is already `jira issue move KEY STATUS` on the Epic key. Clicking an Epic Card Opens (ADR-0005). Last opener persists locally, like Filter chrome, not as a Preset. The Epics group stays on All epics; a row still jumps to that Epic's children on All stories. Favourites and Presets do the same. We rejected one Board that flips via Scope because Scope stays the children list, and rejected a TOML of Pipes because the process already lists Epics after boot.
