# First-release Board layout

Epics are not Cards. They live in the left pane. Clicking a Card Opens its Jira URL in the right pane; `jira open` still resolves that URL. Remote Jira (jira.dell.com and the rest) sends `X-Frame-Options` / CSP that refuses an iframe from this origin, so the pane shows a link instead. Same-origin Fake Jira `/browse/KEY` still embeds. Columns are the statuses present in the payload; empty workflow states stay hidden. The process binds `127.0.0.1:5173`. `HOST=0.0.0.0` is the LAN override. Fake Jira always advertises `http://127.0.0.1:${port}` so jira-cli can reach it.
