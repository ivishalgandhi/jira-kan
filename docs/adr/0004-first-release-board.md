# First-release Board layout

Epics are not Cards. They live in the left pane, filled by `jira issue list -tEpic --raw` and merged with any Epic keys remembered from Cards. Clicking an Epic still shows children Cards on this Board; a Kanban whose Cards are Epics is All epics, a later Board with its own opener (ADR-0009), not a select toggle. Clicking a Card Opens the Issue in the right pane (ADR-0005). Remote Jira (jira.dell.com and the rest) sends `X-Frame-Options` / CSP that refuses an iframe from this origin, so the pane shows fields and a link instead. Same-origin Fake Jira `/browse/KEY` still embeds. Columns are the statuses present in the payload; empty workflow states stay omitted. The process binds `127.0.0.1:5173`. `HOST=0.0.0.0` is the LAN override. Fake Jira always advertises `http://127.0.0.1:${port}` so jira-cli can reach it.
