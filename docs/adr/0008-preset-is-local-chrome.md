# A Preset is local chrome, not Scope

Linear's View is the query. Our Scope is the jira-cli list. A Preset names a copy of the last-used Filter, Sort, and Hide blob (ADR-0006) and stays on this machine like Favourites, in its own `localStorage` key. Apply copies that snapshot into last-used; later Filter/Sort/Hide writes last-used only. Search, selected Epic, and Filter hide-row do not touch the Preset list. Names follow Folder rules (trim, reject empty, unique case-insensitively) and stay in create order. The Presets group is always shown, default open, collapsed in the same blob as Favourites. Create and overwrite live on Presets `...`; there are no built-in names and no applied highlight. Sharing, Scope flags, hiding individual Cards, and a Kanban of Epics are out. Linear product pages that informed this: Custom Views, Filters, Display options, Board layout, Favorites (`linear.app/docs/...`). Chrome tokens stay in `docs/research/linear-ui.md`.
